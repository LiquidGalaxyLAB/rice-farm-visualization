\# Rice Farm Agriculture Visualization on Liquid Galaxy



An interactive geospatial storytelling platform that visualizes rice agriculture across India using the Liquid Galaxy multi-screen visualization system.



\## Project Overview



This project transforms agricultural datasets into an immersive multi-screen storytelling experience using Google Earth and KML visualizations. The system consists of a Flutter mobile controller app and the Liquid Galaxy visualization engine.



\## Tech Stack



\- Flutter (Mobile Controller)

\- KML (Map Visualizations)

\- Google Earth (Geospatial Rendering)

\- Liquid Galaxy Platform (Multi-screen Display)

\- Linux + SSH (Rig Communication)

\- Flutter TTS (Narration)

\- Google Maps (Synced Navigation)
